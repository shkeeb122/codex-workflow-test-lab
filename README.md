# codex-workflow-test-lab

A Python Flask web application providing health check and hello endpoints.

## Setup

Install dependencies:

```bash
pip install -r requirements.txt
```

## Running the Application

```bash
python app.py
```

## Endpoints

- `GET /health` - Health check endpoint
- `GET /hello` - Hello endpoint

## Testing

Run the test suite:

```bash
python -m unittest -v
```
